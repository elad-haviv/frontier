# Chronicles: laying out a history

A **chronicle** is a timeline you build and drag. You put events on it, roughly or exactly, and see
at a glance what comes before what, what overlaps and how long things last. Maps that change with
time read a chronicle too, so the same work that clears up your history also drives your maps.

A chronicle is a **workbench for one version of a history**. Its numbers are working numbers, not
lore. Nothing you do on a chronicle is written into a note.

## The Chronicles list

Choose **Chronicles** in the left bar (a scroll icon). The page lists every chronicle you have, and
for each one:

- its title, which opens it;
- how many events it has ("3 spans", or "1 span");
- **the main chronicle**, if it is the one maps use;
- "unsaved changes" or "not saved as a version yet", if it has changes you have not saved as a
  version.

If you have none yet, it says "No chronicles yet. Make the first below."

### Make a new chronicle

1. Under **New chronicle**, type a **Title**.
2. Press **Make the chronicle**.

You land on an empty timeline that says: "Lay out a history. Add the events you know, rough dates
are fine. Year 0 is whatever you place first." with a **+ Add the first event** button.

**Tip:** You can have several chronicles, for example one for the world's history as you believe it
now and another to try out a different order of events. See [Versions of a
chronicle](#versions-of-a-chronicle).

If a chronicle file in your library is broken, the list shows a notice such as "... is not shown as
a chronicle" with the reason.

## A tour of the chronicle page

The page is one screen. Rows of events are on the left; bars on a real ruler are on the right, like
a project plan. You only ever say *when*: there are no tasks, resources or percentages.

**The header**

| Item | What it does |
| --- | --- |
| **←** | Back to the list of chronicles |
| The title | The chronicle's name. Rename it from the **⋯** menu |
| **★ Main · maps use this** / **Make main** | Whether maps that change with time read this chronicle. Press **Make main** on any other chronicle to switch |
| The save note | "Saved as a draft", "Saving…", "Unsent: kept on this device", "Not saved" |
| **⚠ n doesn't fit** | Appears in red only when something breaks one of your rules. Opens a list with fixes |
| **🗺 Open map at 200** | Opens a map at the year shown by the blue line. With several maps it becomes a menu of them |
| **⋯** | More actions (below) |

**The toolbar**

| Item | What it does |
| --- | --- |
| **+ Add** | Add an event (shortcut: N) |
| **Years / Decades / Centuries / Millennia** | The zoom level |
| **Fit** | Zoom so everything placed is in view (shortcut: F) |
| **Undo**, **Redo** | Step back and forward through your changes |
| **Year 0 = First Landing** | A menu to choose what year 0 is. It reads just **Year 0** if year 0 is not the start of an event |
| **Timeline / List** | Switch between the chart and a plain list |

**The chart**

- **Left column:** the events, with a column heading **Event** and **When**. Each group has a header
  row you can fold. An event shows a diamond (a single moment) or a square (lasts a while), its
  name, a red ⚠ if it breaks a rule, and when it happens, such as "270–290 → 300".
- **Right area:** the ruler across the top, one row per event, and a thin summary bar on each
  group's header row.
- **The blue line** marks the year that maps show. See [The main chronicle and
  maps](#the-main-chronicle-and-maps).
- **The details panel** opens on the right when you select an event.

Under the chart a note reminds you: "Working numbers, not lore. Nothing here is written into a
note."

### The ⋯ menu

| Item | What it does |
| --- | --- |
| **Rename** | Rename the chronicle |
| **Add a group** | A new group (a folding header) |
| **Units…** | Your own units, such as generation |
| **Compare lengths with real history…** | Opens the comparison |
| **Make main** | (On a phone) make this the main chronicle |
| **Copy, to try another version** | Makes a copy and opens it |
| **Show another version underneath…** | Draws another chronicle as grey bars in the same rows |
| **Delete the chronicle** | Deletes it (asks first) |

Copy, Make main, Delete and Show another version underneath need a connection to the server and are
greyed out when you are offline.

## Add an event

An **event** is either something that **lasts a while** (a bar) or **a single moment** (a diamond).

### The Add an event form

Press **+ Add**, press **N**, use a group's **+ Add to ...** row, or press the round **+** on a
phone.

1. **Name or entry.** Type a name. As you type, matching entries are offered, each marked "📖 ... ·
   link to this entry". Pick one and the event is named after the entry and linked to it.
2. **Starts** and **Ends** (both optional). Type dates in the short forms below. For a single moment
   the field is called **When** and there is no Ends.
3. **Group.** Which group it goes in. It starts as the group of the event you have selected.
4. Tick **A single moment** if it is a moment, not a stretch of time.
5. Press **Add**.

A name is required: "Give it a name." If a date cannot be read, the form says which box and why.

### Quicker ways on a desktop

- **Drag across an empty part of a row** to draw a bar there. A label shows the years as you
  drag.
- **Double-click an empty spot in a group's last row** to drop a single moment named "New event" at
  that year; its name is ready to type.
- **Double-click** the **When** cell of an event with no dates to type its dates right there.

### Events with no dates yet

An event with no dates is not lost. It shows as a dashed box in its row: "No dates yet · drag onto
the timeline" (or, when only its length is known, "· 60–175 years · drag to place"). **Drag the box
onto the chart** and its start lands where you drop it.

## Say when: typing dates

Every date box (in the Add form, in the When cell, in the details panel) understands the same short
forms. You never have to be exact.

| Type | Meaning |
| --- | --- |
| `300` | Exactly year 300 |
| `270-290` or `270 to 290` | Some time from 270 to 290 |
| `about 280`, `around 280`, `circa 280`, `c. 280`, `~280` | A rough date. "About" reaches one step of the number's last non-zero digit: about 280 is 270–290, about 4000 is 3000–5000. A number ending in another digit reaches 5 either way |
| `280 ±10` | 270 to 290 |
| `-50` or `50 before` | 50 years before year 0 |
| `-50 to -30` | A range before year 0. Use "to" so the minus is not read as a dash |
| `open` | In **Starts**: older than anything shown. In **Ends**: still going |
| `3-5 generations` (in **Lasts**) | A length, using your own unit (see [Units](#units-3-5-generations)) |
| `400`, `350-450 years` (in **Lasts**) | A length in years. Decades, centuries and millennia also work |
| `with First Landing` | A **tie**: starts (or ends) when First Landing does |
| `10 after The war`, `20-40 before The kingdom` | A **tie** with a gap (see below) |

Numbers with commas ("1,200") and typographic dashes and minus signs are understood.

### Starts, Ends and Lasts

In the details panel an event has three boxes: **Starts**, **Ends** and **Lasts**. Fill in **any
two** and the third is worked out and shown in grey ("10–30 (worked out)"). If you fill in all
three and they disagree, the panel says: "These three don't agree: its length does not fit between
its start and end." and the event gets a red mark.

A date in a rough form is drawn as a range, not a point. See [How a bar is
drawn](#how-a-bar-is-drawn).

### If a date is not understood

The box shows a message under it, for example "Type a year such as 300, a range such as 270-290,
"open", or "10 after The war"." Fix the text and press Enter, or click away.

## Drag events on the timeline

On a desktop you can edit the timeline directly.

| To do this | Do this |
| --- | --- |
| **Move** an event | Drag the middle of its bar |
| Change **only its start or end** | Drag the left or right end of the bar |
| Move several events at once | **Shift-click** each (or a group's header), then drag one |
| **Place** an event with no dates | Drag its dashed box onto the chart |
| **Draw** a new bar | Drag across an empty part of a row |
| Move an event to another group | Drag its row in the left list onto another group, or use **Group** in the details panel |

While you drag, a label follows the pointer, for example "The war: 280–300 (+10 yrs)". Moves **snap**
to a round number of years, depending on the zoom: 1 year at Years, 5 at Decades, 10 at Centuries
and 100 at Millennia.

Good to know:

- Dragging an event with soft (rough) ends moves the **whole range**. How rough an end is can only be
  changed by typing.
- Dragging an event that other events are tied to moves them with it. See [Ties](#ties-events-that-follow-each-other).
- Everything you drag can be undone with **Undo** (Ctrl+Z).

### How a bar is drawn

| What you see | What it means |
| --- | --- |
| A **solid** bar | Where the event is surely going on: from the latest it could start to the earliest it could end |
| A **hatched, fading end** | A rough date: the event starts (or ends) some time within the faded part. A small tick marks each end of the range. Hover to read it: "starts some time from 270 to 290" |
| A bar running off the **left edge** with **‹** | An open start: older than anything shown |
| A bar running off the **right edge** with **›** | An open end: still going |
| A **diamond** | A single moment. A rough moment has whiskers from its earliest to its latest year |
| **⛓** | Tied to another event |
| **📖** | Linked to an entry |
| **🗺** | Something on a map follows this event |
| A **red outline** and ⚠ | It breaks a rule |
| A **dashed box** "No dates yet" | The event has no dates. Drag it onto the chart |

## Ties: events that follow each other

A **tie** makes one event follow another. It is the only thing that moves an event you did not touch.

> Example: you type **Starts**: `with First Landing` for "Earth memory fades", and **Lasts**:
> `3-5 generations`. Now "Earth memory fades" begins exactly when First Landing begins, and is drawn
> as long as three to five generations. Move First Landing and it follows.

### Tie forms

| Type | The event ... |
| --- | --- |
| `with First Landing` | starts (or, in **Ends**, ends) together with First Landing |
| `with the end of First Landing` | starts (or ends) when First Landing ends |
| `10 after The war` | starts 10 years after The war **ends** |
| `20-40 before The kingdom` | starts 20 to 40 years before The kingdom **starts** |
| `5 after the start of The war` | 5 years after The war **starts** |
| `10 before the end of The war` | 10 years before The war ends |

A tied date shows **⛓** on the bar and a dotted line to what it is tied to. In the details panel the
date box shows the tie in words.

### Working with ties

- **Moving the anchor moves what is tied to it.** Move First Landing and the events tied to it follow,
  and the page shows them moving while you drag.
- **Dragging a tied event** keeps the tie and changes its gap. A bar tied "10 after The war" that you
  drag 10 years later becomes "20 after The war".
- **Untie.** In the details panel a tied box has **⛓ Untie**. It keeps the numbers the event has now,
  and removes the tie.
- **Circles are refused.** You cannot tie A to B if B is already tied to A, directly or through
  others.
- A tie needs another event named exactly (case does not matter). If the name is not found you get an
  error message under the box.
- A tied range that runs from before to after ("-5 to 5") is shown in a plain written form that
  cannot be typed back in as a tie; type it again to change it.

### "Events can be placed from what you said"

If an older chronicle has events with no dates but with statements such as "starts with" or "is
after" a placed event, a banner may offer: "3 events can be placed from what you said." Press
**Place them** to turn those statements into ties, or **Not now**. Nothing happens without your
click, and the banner does not come back once you have answered.

## Rules and "doesn't fit"

A **rule** is a statement that is only *checked*; it never moves anything. Use rules to say what
must be true of your history and let Frontier tell you when it is not.

Rules you can add (in the details panel, under **Must fit**):

- is after
- is before
- is during
- starts with
- ends with
- overlaps
- is longer than
- is shorter than

### Add a rule

1. Select an event.
2. In the details panel, under **Must fit**, pick the kind of rule, then **Choose an event...**.
3. Press **Add the rule**.

Each rule is shown with a mark:

| Mark | Meaning |
| --- | --- |
| ✓ | Fits |
| ⚠ (red) | Doesn't fit, or goes in a circle, or names an event that was removed |
| ? (amber) | May not fit (not certain, because dates are rough) |
| ? (grey) | Cannot tell yet, or not checked (a date is missing) |

For a rule that doesn't fit, the panel explains why in a sentence and offers one-click fixes such as
**Move The war (start 270)**, and **Remove the rule**. Fixes can be undone.

### The "doesn't fit" list

When anything is red, a pill **⚠ n doesn't fit** appears in the header. It opens a list:

- Events whose own start, end and length "don't agree".
- Rules that don't fit, with **Show both** (selects both events so you can see them), the fix
  buttons, and **Remove the rule**.
- Grouped below, folded: "n may not fit", "n cannot be told yet" and "n hold".

If you have rules and none are red it says **Everything fits.** With no rules it says "No rules yet.
Select an event and add one under Must fit."

**Tip:** Rough dates make Frontier cautious. "May not fit" means the rule fits for some possible years
and not others. Narrow a date to resolve it.

## The details panel

Select an event (click its bar or its row) and its details open on the right. On a phone they open as
a sheet. Close with **Close** or Esc.

| Part | What it holds |
| --- | --- |
| **Name** | Rename the event |
| **Group** | Move it to another group |
| **Lasts a while / A single moment** | Switch the kind. Changing to a single moment drops its end and length |
| **Starts, Ends, Lasts** (or **When**) | Type dates; a hint line lists the forms. **⛓ Untie** removes a tie |
| **Count years from its start (make it year 0)** | See [Year 0](#year-0) |
| **Must fit** | Rules about this event, with marks, explanations and fixes; a form to add one |
| **Entry** | Link it to an entry |
| **On maps** | Maps that follow this event |
| **Note** | A free note about the event |
| **Duplicate**, **Delete** | Copy the event (named "... (copy)"; the copy is not linked to an entry) or remove it |

If a length was written in a unit you have since changed, the panel shows: "Written with generation
as 20 to 35; now 25 to 40." with a **Recalculate** button.

## Groups

A **group** is a folding header row that collects related events, such as "Humans", "Ezob" or
"Wars". Colours help you tell groups apart.

- **Fold or unfold:** click the ▾ / ▸ at a group's left, or press Space on a group. Which groups are
  folded is remembered on this device.
- **Rename:** click the group's name and type.
- **Group menu (⋯ beside the name):** **Add an event to ...**, **Next colour**, **Move up**,
  **Move down**, **Delete the group**.
- **Add a group:** the **⋯** menu in the header, **Add a group**.
- **Delete the group:** asks first, then moves its events into the group above (or below if it was
  the first). The last group cannot be deleted.

Every chronicle has at least one group.

## Year 0

Year 0 is the zero of the ruler. By default it is whatever you place first; you can choose it.

- **Toolbar:** open **Year 0 = ...** and choose **Count from the start of ...** for any placed event.
- **Details panel:** **Count years from its start (make it year 0)**.

Choosing a new year 0 shifts **every number by the same amount**; nothing else changes and no
distance is altered. Dates before year 0 are negative (`-50`).

## Zooming and finding your way

Four levels: **Years** (about 7 pixels a year), **Decades**, **Centuries** and **Millennia**. The
timeline can show up to about 100,000 years.

- Press the buttons in the toolbar, or keys **1** to **4**.
- **+** and **-** zoom in and out by a step. **Ctrl + scroll wheel** (or pinch on a touch screen)
  zooms smoothly.
- **Fit** (or **F**) shows everything placed.
- Zooming keeps the year under your pointer, or the middle of the view, where it was.
- Scroll sideways to move through time; scroll up and down for more rows.

If nothing has dates yet, the chart says: "Nothing is placed in years yet. Type a date in any row, or
drag a dashed box onto the timeline."

## List view

Press **List** (beside **Timeline**) for the same events as a plain list in order of start date:

- Events are under headings by century: **Before year 0**, **Year 0 to 99**, **Year 100 to 199**, and
  so on. An event with an open start goes under **Older than anything shown**.
- Each line shows when it happens, a square or diamond, its name, a red ⚠ if it breaks a rule, and its
  group.
- A line marked **Maps: year 200** sits between events to show where the map year falls.
- **No dates yet** is last.
- Click an event to select it and open its details.

The List view is the easiest way to read a chronicle on a phone, and an alternative for anyone who
prefers not to use the chart. The zoom buttons are greyed out in List view.

## Linking events to entries

Link an event to the entry it stands for, such as the event "The Treaty" to the entry "Treaty of Ash".

- **When adding:** pick an entry from the suggestions in the Add form.
- **Later:** in the details panel, under **Entry**, use the picker to find an entry. The bar gets 📖.
- **Open the entry:** the entry's title is a link in the panel.
- **Unlink:** **Unlink** beside it. If the entry was deleted, the panel says "Its entry was removed."
  and offers **Unlink**; the event keeps its name.
- If two events in one chronicle link to the same entry, the panel notes it: "Another event here is
  linked to the same entry. Maps follow the first of them."

On the other side, an entry that is linked from a chronicle shows **On chronicles:** under its title,
with a link to each event.

## Units: "3-5 generations"

Open **⋯, Units...** to define words of your own that stand for a range of years, such as
**generation: 20 to 35 years**. Then a length can be typed as "3-5 generations".

- To add one: type the unit's name, the lowest and highest years, and press **Add the unit**.
- To change one, edit its name or numbers. A unit's lowest cannot be above its highest, and both must
  be 0 or more.
- Changing a unit does not change lengths automatically: each length written in it offers
  **Recalculate** in its event's details.
- A unit used by an event's length cannot be deleted (its **Delete** is greyed out).

Years, decades, centuries and millennia are always understood without defining them.

## Compare lengths with real history

Open **⋯, Compare lengths with real history...** to put your events' lengths beside real durations,
as bars from a common start on one scale. It helps you ask "does this empire last longer than the
real ones I'm drawing on?"

- Each bar is solid up to its lowest value and fades to its highest.
- **Add a span:** pick an event that has a length (up to four).
- **Add a real-world case:** pick one of the supplied cases (up to four), each with its source, what it
  is counted from and to, and a caveat:
  - **Living memory**, 80 to 100 years.
  - **Norse Greenland, settlement to abandonment**, 420 to 470 years.
  - **Hebrew without native speakers**, 1650 to 1700 years.
- **Add a case of your own:** give it a name, lowest and highest years, and optionally what it is
  counted from and to and a source.
- **Take away** removes a bar from the comparison only.
- Clicking an event's name closes the dialog and selects it.

Cases are only rulers: they never flag anything. They are measured in Earth years and about humans.

## Versions of a chronicle

There are three ways to work with more than one version of a history.

### Copy, to try another version

**⋯, Copy, to try another version** makes a copy of the chronicle and opens it. Change the copy
freely and keep the original as it was. The copy is a normal chronicle on the list.

### Show another version underneath

**⋯, Show another version underneath...** lets you pick another chronicle. Its bars are drawn as **grey
ghosts in the same rows**, matched to your events by id and then by name, so you can see how the two
differ. Events that differ are **outlined**. A note above the chart reads "Grey underneath: ... Outlined:
differs." with **Hide**. To stop, use **⋯, Stop showing ... underneath**.

The other chronicle is lined up with this one on a common event (preferably the year-0 event), so you
compare the *shape* of the histories rather than being thrown off by a different zero.

### Saved versions of the library

Like any entry, chronicles are saved to the library as drafts first. See "Unsaved" (or
"Unpublished") in the left bar to save a version of your changes along with the rest of your work.
The Chronicles list marks a chronicle "unsaved changes" or "not saved as a version yet" until you
do.

## The main chronicle and maps

Maps can **change with time**: markers, paths and zones can exist only between certain years. They
read the **main chronicle** to know when things happen.

- **Main chronicle:** one chronicle is marked **★ Main · maps use this**. On any other, press **Make
  main**. A map's time bar also lets you choose another chronicle for that map.
- **The blue line** on the timeline is the year the maps show. **Drag its flag** in the ruler to set the
  year, or select an event and press **Y** to put the line at that event's start. The year is
  remembered per chronicle on this device.
- **🗺 Open map at 200** in the header opens a map at that year, with this chronicle. If you have
  several maps, it is a menu of them.
- **🗺 on a bar** means something on a map follows that event. The details panel's **On maps** section
  lists them ("Sample world · 1 feature follows this") and opens the map at the event's start.
- **From the map:** in a map's **Time** bar, **Open timeline ↗** opens this chronicle with the blue line
  at the year the map is showing.

If you open a chronicle with `?t=` in its address, the blue line starts at that year.

## On a phone

The chronicle is the same horizontal timeline, so it reads like the desktop one and like the map's
time slider.

- **Tap** a bar to select it. A **bottom sheet** opens with its details. Tap the sheet's handle to
  unfold the rest.
- **Press and hold, then drag** a bar to move it (with a short buzz). Plain swipes always pan the
  chart, so nothing moves by accident.
- The selected bar shows end handles to stretch it.
- **Pinch** to zoom. The zoom chips are **Yrs**, **Decades**, **Cent.** and **Mill.**
- The round **+** at the bottom right adds an event.
- Undo, Redo, **Fit everything**, **Make main** and the map links are in the **⋯** menu.
- **List** is often easier for reading.

On a desktop, with the chronicle page open and no box focused:

| ← / → | Move the selected event one step earlier / later (a step is the zoom's snap) |
| Shift + ← / → | Move it ten steps |

| Alt + Shift + ← / → | Move only its **start** |

The chart can be used with a screen reader: each bar is a button labelled like "The war, starts 270
to 290, ends 300, doesn't fit a rule".

## Saving, offline and deleting

- **Changes save as you make them**, as a draft on the server. The note in the header tells you the
  state: "Saved as a draft", "Saving...", "Unsent: kept on this device" (you are offline; it will
  send itself) or "Not saved" (the server refused it; the reason shows in a banner).
- **Offline:** you can keep editing; changes wait on the device. Copy, Make main, Delete and Show
  another version underneath need a connection.
- **Two devices:** if the same chronicle is changed in two places, the changes are merged. Tied
  numbers are worked out again afterwards and saved if one moved.
- **Delete the chronicle:** **⋯, Delete the chronicle**. It is marked for deletion and goes when you save a
  version. Until then it can be brought back from the unsaved changes.
- **Delete an event:** select it, press **Delete**, or use **Delete** in the details. Undo brings it back.

## Troubleshooting

| What you see | What to do |
| --- | --- |
| "Give it a name." in the Add form | Type a name before pressing **Add** |
| A date box shows a red message | The text could not be read. Use one of the forms in [Say when](#say-when-typing-dates) |
| "First Landing is already tied to this" or a similar refusal | A tie would go in a circle. Tie to a different event, or untie the other one first |
| An event is a dashed box and will not appear on the ruler | It has no dates. Drag the box onto the chart, or type a date |
| "These three don't agree" | Starts, Ends and Lasts contradict each other. Clear one of them and let it be worked out |
| An event is red but has no rule | Its own dates disagree (see above). Open the **⚠** list |
| ⚠ "doesn't fit" appears and you do not understand why | Open the pill: each line says in a sentence why, and offers a fix |
| "Make main" is greyed out | You are offline. It needs the server |
| A map does not change with time | Make sure a chronicle is main (or choose one in the map's time bar), and that events are placed in years |
| The blue line is not where you expect | It starts at the address's `?t=`, then the last year used on this device, else 0. Drag its flag, or press **Y** |
| A chronicle is missing from the list | A notice under the list says which file could not be read and why |
