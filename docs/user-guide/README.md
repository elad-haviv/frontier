# Frontier user guide

Frontier is a web app for one author to write, read and explore a fantasy world kept as Markdown
notes. This guide covers every feature that is built today.

| Chapter | What it covers |
| --- | --- |
| [1. Getting started](01-getting-started.md) | Words used in the app, signing in, the shell and side bars, the folder tree, search and the switcher, keyboard shortcuts, saving and offline use, Settings, saving versions, the Inbox, Import |
| [2. Entries and writing](02-entries-and-writing.md) | Reading and writing entries, the editor and toolbar, links, images, tables, properties, comments, history, export, the Gallery, the Graph |
| [3. Maps](03-maps.md) | Flat maps and globes, places, paths, zones, layers, styles, terrain, Find areas, Find paths, biomes, Explore |
| [4. Chronicles](04-chronicles.md) | Timelines of events, typed dates, ties, comparing, versions, the year line on maps |
| [5. AI](05-ai.md) | Providers and keys, models and the spending cap, Ask, Talk, writing help, field proposals, dictation, what is sent where |
| [6. Administration](06-administration.md) | For whoever runs the server: settings, deployment, passwords, passkeys, backups and restore |

## Where to start

- **New here:** read chapter 1, then chapter 2.
- **Drawing a world:** chapter 3.
- **Planning history:** chapter 4.
- **Using the AI:** set it up with chapter 5 first; every AI feature needs a key.
- **Running the server:** chapter 6.

## A note on wording

Frontier keeps its own library by default, so changes are saved as **versions** ("Unsaved" entries,
"Save a version"). If your library is connected to GitHub, the same things are called
**Unpublished** and **Publish**. The chapters explain both.
